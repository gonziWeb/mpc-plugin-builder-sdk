# Monolith

A guitar rig builder for the MPC, by Gonzi Audio. Insert effect, version 0.4.0 (prototype).

Six blocks in a row. You choose what each block is, and the order of the blocks is the order of
the signal, so you build the chain you want: pedal, amp, cabinet, delay, reverb, in any order.
It plays **Neural Amp Modeler** captures (`.nam`, including the A2 format used on TONE3000) and
**cabinet impulse responses** (`.wav`) that you copy into the plugin's folder.

Built with the official MPC Plugin SDK. No root, no firmware change.

## Block types

| Type | What it is | Knob 1 | Knob 2 | Knob 3 | Knob 4 |
|---|---|---|---|---|---|
| Off | nothing | | | | |
| Gate | noise gate | Thresh (-90..-20 dB) | Release (10 ms..1 s) | | |
| Amp | a `.nam` capture of an amp or a full rig | Gain (into the capture, -24..+24 dB) | Size (Lite / Full, A2 captures only) | | |
| Pedal | a `.nam` capture of a pedal | Gain | Size | | |
| Cab IR | a cabinet impulse response, zero latency | Lo Cut (Off, 20..500 Hz) | Hi Cut (2..20 kHz, Off) | Mix | |
| EQ | tone control | Bass (110 Hz) | Mid | Mid Freq (200 Hz..3 kHz) | Treble (4 kHz) |
| Drive | built-in drive pedals, 10 presets | Drive | Tone | Tight (low cut before clipping) | Mix |
| Delay | built-in delays, 8 presets | Time (30..1200 ms) | Feedback | Tone | Mix |
| Reverb | built-in reverbs, 8 presets, stereo | Decay | Damp | Mix | PreDelay |

**Amp or pedal?** Both are Neural Amp Modeler captures; they have separate lists and separate pictures. A
capture is a pedal when it sits in a folder whose name contains "pedal" (use `Content/NAM/Pedals/`), when its
file name contains "pedal", or when its own metadata says so (`gear_type: pedal`). Everything else is an amp.

**Presets of the built-in effects** (the File control of the block; choosing one moves the four knobs to its
starting positions, then they are yours):

- Drive: Screamer, Screamer Hot (mid-forward overdrive); Blues, Blues Edge (open, low gain); Rodent, Rodent
  Heavy (hard-clipping distortion); Fuzz, Fuzz Wall; Clean Boost, Treble Boost.
- Delay: Digital, Slapback, Long Lead; Tape, Tape Worn (wow, saturating dark repeats); Analog, Analog Dark;
  Ping Pong (stereo).
- Reverb: Room, Studio; Hall, Cathedral; Plate, Bright Plate; Spring, Surf Spring.

These are our own simple circuits "in the spirit of", not models of particular pedals.

Every block also has **File** (which capture or IR, for NAM and Cab IR blocks), **On** and **Level**.
Choosing another type for a block puts its knobs back to that type's defaults.

The chain is mono (a guitar is mono). A Reverb block makes the signal stereo; a mono block placed
after it folds it back to mono, so put the reverb last if you want it wide.

## Your own captures and IRs

On the drive, open `VST2 Plugins/Gonzi Audio - VST - Monolith/Content/` and copy:

- `.nam` captures of amps into `NAM/`, captures of pedals into `NAM/Pedals/`
- `.wav` impulse responses into `IR/`

Sub-folders are fine (one per pack). Files dropped anywhere else in `Content/`, or loose in the
plugin folder, are found too. The list is read when the plugin is added to a track: after copying
new files, reload the project (or remove and re-insert the plugin).

A project remembers each block's file by **name**, so adding files later does not change which one
a saved project uses. Names are shown up to 22 characters; short file names read best on the screen.

Impulse responses: any sample rate, mono or stereo (the first channel is used), up to 8192 samples
at 44.1 kHz (186 ms); longer files are cut with a short fade. Levels are normalised.

## Pages

- **RIG**: everything on one page. The top is the pedalboard: the six blocks drawn as gear, in signal order
  (an amp for a NAM block, a cabinet, a pedal for each effect, a dashed outline for an empty place), each
  with its lamp (On), its type and the name of its capture or IR; the seventh box is the input / output.
  **Touch a block and its settings appear underneath**: Type (double-tap for the list), File, On, Level and
  its knobs. Only the knobs the type uses are shown. Touch the In / Out box for In Chan, Quality, DI Comp,
  Input and Output. Settings are edited by touch and with the data wheel (double-tap a knob for the big one).
- **BLK 1-2**, **BLK 3-4**, **BLK 5-6**: the same settings, two blocks per page, for the hardware Q-Link
  knobs. (A page has one fixed knob map on the MPC, so on RIG the Q-Links cannot follow the selected block;
  there they only drive the In / Out settings.)

The skin is generated by `python3 plugins/Monolith/tools/make_skin.py [--preview out.png]` (Pillow) into
`skins/`, which the build copies as is: after changing `ui.json` or parameters, delete `skins/`, build,
make_skin, build. `ui.json` has helper pages E1..E6 that make_skin folds into RIG.

## Input and output

- **DI Comp** (off by default): a treble lift (+8 dB shelf from 2.8 kHz) for a passive guitar plugged straight
  into the MPC's line input, which loads the pickups and dulls them. It is a correction after the fact, not a
  buffer: the loss happens in the cable before the converter, and the lift raises hiss with the treble. A
  buffered pedal or a DI box in front of the MPC is the real fix.
- **Output limiter** (always on): transparent up to -3 dBFS, then rounds peaks off below 0 dBFS, so a hard
  pick attack no longer clips the track. If it works all the time, turn Output or the last block's Level down.

## Programs

Amp + Cab, Boosted Amp, Lead Echo, Ambient Wash, Pedal + Amp (a Pedal block in front of the amp: it
passes the signal through until you have put a pedal capture in `Content/NAM/Pedals/`), Cab Only (for a real preamp or pedal into the MPC).

## CPU: read this

Neural captures are heavy for the MPC's processor. Figures for a first-generation MPC One are
**estimates**, scaled from measurements other people published for the same chip, not measured by
us yet:

| Block | One core of the MPC One (estimate) |
|---|---|
| NAM, A2 capture, Size Lite | about 12-15 % |
| NAM, A2 capture, Size Full | about 60-85 %: on its own at most, expect crackles |
| NAM, older "standard" WaveNet capture | more than a whole core: will not run |
| Cab IR | about 3-6 % |
| Gate, Drive, EQ, Delay, Reverb | about 1 % or less each |

So: use **A2** captures (or the small "nano" / "feather" sizes of older captures), keep Size on
Lite, and count on two NAM blocks at most (pedal + amp). **Quality = Eco** runs the capture at the
MPC's 44.1 kHz instead of resampling to the 48 kHz it was trained at: a little cheaper, and the
tone shifts about 8 % lower in frequency. A block that is Off or switched off costs nothing.

Latency: a NAM block in Hi-Fi quality adds about 1 ms (the resamplers); everything else adds none.
The plugin does not report this to the MPC.

## What is in the box

- `Content/NAM/Example A2.nam`: the example A2 capture from the Neural Amp Modeler Core
  repository (MIT), so that the plugin makes a sound before you add your own.
- `Content/IR/Gonzi 412 Dark`, `Gonzi 412 Bright`, `Gonzi 112 Open`: **synthetic** cabinet
  responses drawn as curves by `tools/make_irs.py`, not recordings of real cabinets. Real IRs
  will sound better.

## Not done / not yet checked

- On an MPC One: 0.1.0 loads, knob names follow the block type; 0.2.0's gear pictures follow the types; a
  guitar plugged straight in plays (crackle on hard attacks, hence the limiter). Not confirmed on the device:
  touching a block to select it (0.3.0), the hidden knobs, the CPU figures.
- No tuner, no parallel paths, no stereo effects before the reverb, no tempo-synced delay.
- The Drive block is not oversampled (some aliasing at high drive).
- No download from TONE3000 on the device: files go through the computer and the drive.
- Switching a block's type or file while playing can click.

## Parameters (order is permanent, 53)

Output, Input, In Chan, Quality, then for each block 1..6: Type ("Block n"), File, On, Level,
K1, K2, K3, K4 (ids `s<n>_type`, `s<n>_file`, `s<n>_on`, `s<n>_level`, `s<n>_k1`..`s<n>_k4`), then DI Comp (0.3.0).
Type choices (append only from 0.2.0; 0.1.0 had another order): Off, Gate, Amp (the NAM type), Cab IR, EQ, Drive, Delay,
Reverb, Pedal (0.4.0). The effect preset lists are append only too.
The order matters to the skin: see `RULES` in `tools/make_skin.py`.

## Building

The Neural Amp Modeler engine is compiled into the plugin (`src/nam_engine.cpp` includes its
sources from `src/NAM/`), so a full build takes several minutes per target.

```
python tools/build.py plugins/Monolith
.sdk-tools/host_sim plugins/Monolith/build/native/monolith.so test --seconds 6 --wav plugins/Monolith/build/test.wav
g++ -O2 -std=c++17 -Iframework gonzi/tools/render_guitar.cpp -o .sdk-tools/render_guitar -ldl
.sdk-tools/render_guitar plugins/Monolith/build/native/monolith.so out.wav 70 -1 0 1 2 3 5
```

Do not shorten the names of the File and K parameters in the constructor: the build reads the
parameter list before the plugin is prepared, when they are still `1 File`, `1 K1`, ... and
`ui.json` refers to those names.
